Steganografi Audio dengan Enkripsi AES

Apa itu Steganografi?

Steganografi adalah seni dan ilmu menyembunyikan pesan rahasia di dalam media lain sehingga keberadaan pesan tersebut tidak diketahui oleh pihak ketiga. Berbeda dengan kriptografi yang membuat pesan tidak dapat dibaca, steganografi menyembunyikan fakta bahwa komunikasi rahasia sedang terjadi.

Steganografi Audio dalam Aplikasi Ini

Aplikasi ini menggunakan steganografi audio dengan menggabungkan teknik enkripsi AES dan pemetaan data ke nada musik. Proses kerjanya:

  1. Pesan pengguna dienkripsi menggunakan algoritma AES-128 dengan kunci 16 karakter.
  2. Ciphertext hasil enkripsi dikonversi ke representasi biner.
  3. Setiap 2 bit dipetakan ke nada musik tertentu (00 = C, 01 = D, 10 = E, 11 = G).
  4. Nada-nada tersebut disusun mengikuti pola lagu "Mary Had a Little Lamb" untuk menghasilkan musik yang alami.
  5. Informasi pemetaan disimpan sebagai metadata dalam file WAV untuk proses dekripsi.
Keunggulan Metode
  • Keamanan Ganda - Kombinasi enkripsi AES dan steganografi.
  • Hasil Alami - File audio yang dihasilkan adalah lagu yang dapat didengarkan secara normal.
  • Metadata Tersembunyi - Informasi dekripsi disimpan dalam file audio tanpa merusak kualitas.
  • Kapasitas Besar - Dapat menyimpan pesan yang cukup panjang dalam satu file audio.
Teknologi yang Digunakan
  • Python - Bahasa pemrograman utama
  • Flask - Framework web
  • PyCryptodome - Library kriptografi untuk enkripsi AES
  • SciPy & NumPy - Manipulasi dan pemrosesan audio
  • Bootstrap - Framework CSS untuk antarmuka pengguna
Catatan Penting:

Aplikasi ini dibuat untuk tujuan edukasi dan demonstrasi. Pastikan untuk menggunakan kunci yang kuat dan tidak mengungkapkannya kepada pihak yang tidak berwenang.
