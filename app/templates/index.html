Sembunyikan pesan rahasia dalam file audio yang digenerate dengan aman menggunakan enkripsi AES dan template lagu "Mary Had a Little Lamb".

Pilih salah satu opsi di bawah untuk memulai:

Enkripsi Pesan

Enkripsi pesan teks dan sembunyikan dalam file audio yang digenerate.

Proses:

  1. Masukkan pesan teks
  2. Masukkan kunci enkripsi (16 karakter)
  3. Klik "Enkripsi & Buat Audio"
  4. Unduh file audio yang dihasilkan

Proses:

  1. Unggah file audio yang berisi pesan

  3. Klik "Dekripsi Audio"

Tentang Noiseless Steganografi Audio

Aplikasi ini menggunakan metode noiseless steganografi audio untuk menyembunyikan pesan rahasia dalam file musik yang digenerate. Proses yang digunakan:

  1. Pesan dienkripsi menggunakan algoritma AES dengan kunci 16 karakter.
  2. Hasil enkripsi dikonversi ke bentuk biner (urutan bit 0 dan 1).
  3. Setiap 2 bit dipetakan ke nada musik dalam lagu "Mary Had a Little Lamb".
  4. File audio dibuat dengan urutan nada musik sesuai pemetaan bit.
  5. Metadata pemetaan bit disimpan dalam file audio untuk dekripsi.

Keunggulan metode ini adalah pesan tersembunyi dalam musik yang terdengar alami bebas dari noise dan tidak mencurigakan.
