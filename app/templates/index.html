Enkripsi Pesan

Enkripsi pesan teks dan sembunyikan dalam file audio.

  1. Masukkan pesan teks
  2. Masukkan kunci enkripsi (16 karakter)
  3. Klik "Enkripsi & Buat Audio"
  4. Unduh file audio yang dihasilkan

Dekripsi Audio

Ekstrak dan dekripsi pesan dari file audio.

  1. Unggah file audio yang berisi pesan
  2. Masukkan kunci dekripsi yang sama
  3. Klik "Dekripsi Audio"
  4. Baca pesan hasil dekripsi

Tentang Steganografi Audio

Aplikasi ini menyembunyikan pesan rahasia dalam file musik yang dihasilkan:

  • Pesan dienkripsi dengan AES-128
  • Data dikonversi ke bentuk biner
  • Setiap 2 bit dipetakan ke nada musik
  • Pesan disimpan ke file audio
